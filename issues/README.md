# Issues Tracking

This folder contains tracked issues, open questions, and development tasks for the Hydrotectonic Model.

## Structure

- `open/` - Active issues requiring attention
- `resolved/` - Closed issues (kept for reference)

## Issue File Format

Each issue file should follow this template:

```markdown
# Issue: [Brief Title]

**Status:** Open | In Progress | Resolved
**Priority:** High | Medium | Low
**Category:** Physics | Data | Documentation | Review Response

## Description
[What is the issue?]

## Context
[Why does this matter?]

## Proposed Resolution
[How might we address it?]

## Notes
[Any additional context, references, or discussion]
```

## Categories

- **Physics** - Quantitative or mechanistic questions
- **Data** - Empirical evidence, citations, calculations
- **Documentation** - Writing, organization, clarity
- **Review Response** - Objections raised by reviewers
