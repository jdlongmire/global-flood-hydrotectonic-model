## Categories

- **Physics** - Quantitative/mechanistic impossibility claims
- **Data** - Empirical evidence contradictions
- **Logic** - Internal consistency problems
- **Scope** - Claims the model doesn't actually make
- **Methodology** - Objections to the research framework

---

## Processing Workflow

1. **Capture** - Record objection verbatim with source
2. **Categorize** - Assign category and assess if in-scope
3. **Triage** - Determine if it's:
   - Already addressed in existing materials
   - A genuine gap requiring work
   - A misunderstanding requiring clarification
   - Out of scope (model doesn't claim this)
4. **Respond** - Point to existing response or flag for new work
5. **Track** - Link to relevant phase if it identifies a gap
