# Phase 0: Repo Discipline and Claim-Scope Locking

**Status:** Active
**Goal:** Prevent goalpost-moving accusations

---

## Deliverables

### 1. Model Contract
- [ ] What IS claimed (explicit scope)
- [ ] What is NOT claimed (explicit exclusions)
- [ ] What would falsify it (kill conditions)

**Output:** `MODEL-CONTRACT.md` in repo root

### 2. Versioned Assumptions Table
- [ ] Permeability k and porosity φ
- [ ] Compressibility β_t
- [ ] Length scales L
- [ ] Viscosity μ
- [ ] Pressure differential ΔP
- [ ] Normal stress σ_n
- [ ] Velocity v
- [ ] Supply sources and geometry

**Output:** `theory/assumptions-v2.5.md`

### 3. Falsifier List
- [ ] Explicit inequalities that must hold
- [ ] Observational disconfirmers
- [ ] Parameter bounds outside which model fails

**Output:** `FALSIFIERS.md` in repo root

---

## Success Criterion

A skeptic cannot accuse the model of moving goalposts without being dishonest.

## Notes

This phase is foundational. All subsequent phases depend on having locked scope and explicit assumptions.
